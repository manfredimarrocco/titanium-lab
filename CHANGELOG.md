# Changelog

## 0.2.4 — 2026-10-12

- Allineata alla release la versione interna usata da interfaccia, report e nuovi file di lavoro.
- URL degli asset e dell’applicativo con versione esplicita per evitare copie obsolete nella cache.

## 0.2.3 — 2026-10-12

- Collegamenti repository e download configurabili negli attributi dello shortcode, con controllo HTTPS e host GitHub; nessun URL personale nei sorgenti.
- Selettore file collegato al documento durante la scelta e rimosso dopo importazione o annullamento.
- Documentazione pubblica aggiornata e sezione download pronta per GitHub.

## 0.2.2 — 2026-10-12

- Verifica dei sorgenti e delle parti XML del template; rimozione delle attribuzioni nominali, degli URL personali e dei metadata autore dai file destinati alla distribuzione.
- Licenza MIT per il codice originale.

## 0.2.1 — 2026-10-12 · candidata locale

- Pagina Lab con una sola demo TITANIUM, resa coerente con il tema attivo osservato.
- Plugin WordPress indipendente, shortcode `[mm_grc_lab]`, iframe sandbox avviato su richiesta, vista espandibile e download template.
- Nessuna pagina generata o pubblicata automaticamente, nessuna modifica al tema o navigazione globale.
- Collegamenti GitHub attivabili solo con URL reali dopo creazione autorizzata.
- Pacchetti sorgenti, plugin e standalone, con istruzioni e attribuzione delle fonti.
- FNCDP: nel candidato di distribuzione solo riferimenti e domande originali, in attesa di condizioni esplicite per redistribuire il testo. Prototipo locale 0.2.0 preservato.
- Rifiuto di file con VBA e date 1904; controllo della dimensione dichiarata delle parti ZIP prima di decomprimerle.

## 0.2.0 — 2026-10-12 · prototipo locale

Workspace con sei tipi di grafici, perimetro, cataloghi, evidenze, piano azioni, import/export Excel, file di lavoro JSON, rilevazioni storiche per perimetro e report stampabile. Valutazioni demo sintetiche; nessun salvataggio cloud.
